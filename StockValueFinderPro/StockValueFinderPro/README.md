# Stock Value Finder Pro
Windows: install Python 3.12 from python.org, extract this folder to a local folder such as C:\StockValueFinderPro (avoid OneDrive), double-click setup.bat, then start.bat. Open http://localhost:8501 if browser does not open. No activation or API key needed. Stop with Ctrl+C.
Manual PowerShell: `py -3.12 -m venv .venv`, then ` .\.venv\Scripts\python.exe -m pip install -r requirements.txt`, then ` .\.venv\Scripts\python.exe -m streamlit run app.py`.
Use Yahoo Finance tickers such as NVDA, NESN.SW, SAP.DE, 7203.T. Scanner is a sample universe plus custom symbols, not an exhaustive exchange listing. Watchlist is stored in watchlist.db. Export produces xlsx files. Data is cached 15 minutes and may be delayed or missing. No live API testing is included. Currency mismatches disable per-share valuation, including UK pence quotes. DCF uses provider free cash flow divided by current shares as a proxy for equity cash flow, discounted at required equity return; it does not explicitly model net borrowing, dilution or normalized cash flow. Financials and REITs excluded from DCF. P/E and Graham are independent heuristics. Scores are unvalidated and missing data earns zero. Scenario assumptions are illustrative. No automatic trading or alerts. Run tests with `py -3.12 -m unittest test_valuation`.
